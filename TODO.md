- [ ] **Кромка.** У кожної плити специфікації — які торці кромкуються і чим: напр. `edges: { a1, a2, b1, b2 }` з ключем кромки (`'pvc2'`, `'pvc04'`, `null`) по кожному з чотирьох торців (a — довжина, b — ширина). Правила за замовчуванням задає тип у `parts` (видимі торці фасадів — з усіх боків, полиці — передній торець, задня стінка й приховані торці — без кромки). Типи кромки з товщиною й назвою (`edge.<ключ>` у словнику) — у `config/materials.js` поряд з плитами. У специфікації та CSV — колонка кромки по плитах і підсумок погонних метрів кромки за типами (для API цін). Кромка зменшує розмір деталі до пиляння (розмір у специфікації — готовий, з кромкою; розмір під розкрій = мінус товщина кромки по торцю) — це врахувати в розкрої. Тест: метри кромки для пресета, пораховані вручну.
- [ ] **Напрям текстури.** У плити — чи важливий напрям волокон (`grain: 'a' | 'b' | null`: текстура вздовж розміру a, b або без різниці). За замовчуванням для декорів з текстурою: боковини й фасади — вздовж висоти, полиці, кришка, дно — вздовж ширини; однотонні матеріали — `null`. Чи має матеріал текстуру — у `config/materials.js`. У специфікації першим ставимо розмір уздовж текстури (так заведено в картах розкрою). Розкрій не може повертати деталь з `grain` на 90°; так само `fitsSheet` у `core/common/production.js` (зараз поворот дозволено завжди). Після матеріалів і кольорів: текстура в 3D теж має йти в цьому напрямі.
- [ ] **Розкрій листів.** Кількість листів за реальною розкладкою деталей на лист (а не за площею, як зараз `sheetTotals`, — це лише нижня межа): пропил (ширина пилки, ~4 мм), обрізка країв листа (~10 мм з кожного боку), розміри під розкрій з урахуванням кромки, заборона повороту для деталей з напрямом текстури, деталі, більші за лист (попередження `check.*`). Алгоритм — гільйотинний розкрій (як на форматно-розкрійному верстаті), евристика типу First Fit Decreasing; чиста функція в `core/common/` з тестами на простих розкладках. Результат: листи за матеріалами, відсоток відходу, карта розкрою (координати деталей на кожному листі) — для PNG/PDF-карти розкрою й передачі на виробництво. Підсумок «Листів» у звіті й CSV брати з розкрою, площу лишити довідково.
